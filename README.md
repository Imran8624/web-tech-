# web-tech-
SignShift Delivery is an accessible last-mile logistics web application designed to bridge communication barriers for Deaf, Hard-of-Hearing (HOH), and speech-impaired delivery riders, customers, and merchants. Frontend Framework: React 18 &amp; Vite 3D Graphics &amp; Animations: Three.js &amp; HTML5 Canvas Confetti Styling &amp; UI: TailwindCSS&amp;React Context API
